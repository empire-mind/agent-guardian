# Security Policy

## Supported Versions

Security updates are applied to the latest release on the default branch.
If you are running an older version, please upgrade before reporting.

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Instead, please use one of these private channels:

1. **GitHub Security Advisories** (preferred): open a private vulnerability report via the
   repository's **Security** tab → **Advisories** → **Report a vulnerability**.
2. Open a draft security advisory if the above is unavailable.

Include in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof of concept where possible)
- Affected versions / commits
- Any suggested mitigation

## What to Expect

- Acknowledgement of your report within a reasonable time
- Assessment of severity and affected scope
- A fix or mitigation plan, coordinated disclosure where appropriate
- Credit in the release notes if you wish

## Scope

This policy covers code in this repository. Third-party dependencies are
patched via Dependabot updates; upstream vulnerabilities should also be
reported to the upstream project.

Thank you for helping keep this project secure.
